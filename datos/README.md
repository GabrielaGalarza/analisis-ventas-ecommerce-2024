# Datos del proyecto

Esta carpeta contiene el conjunto de datos utilizado para desarrollar el análisis de ventas de un e-commerce durante 2024.

## Archivo principal

- `ventas-ecommerce-2024.csv`: dataset utilizado para construir el dashboard en Looker Studio.

## Contenido

El conjunto de datos incluye información sobre:

- Fecha de venta
- Producto
- Categoría
- Cantidad
- Venta total
- Región
- Método de pago
- Estado de pago

## Preparación

Antes del análisis se revisó la calidad de los datos, incluyendo completitud, consistencia, validez y relevancia.

El archivo publicado no contiene información personal ni datos sensibles.
